## Notes per WP
B1/B2 — `bs_price` is a template (used with `double`, `Dual<1>` in tests, `Dual<4>` in Greeks). IV is double-only.
B3 — Implement the scatter form exactly (DESIGN §5.2); keep the naive gather version only in the test. L22 must use the α² identity, not a subtraction. Kernel is built once per pricing call (per parameter set), not per path.
B4 — One simulation to the largest maturity serves all quotes. Per-block accumulators hold, per quote: Σy, Σy², Σc, Σc², Σyc over pairs (CV regression), merged in block order. The pilot (purpose 3/4, 8 blocks) runs before the main loop when CV is on. Record wall time and VR factors in NOTES.md.
B5 — Same code path as B4 instantiated with `Dual<4>`; CV forced off. Check the Dual run costs ≤ 8× the double run (record; not a test).
B6 — LM is generic and unit-tested on toy problems before touching rBergomi. Calibration uses a fixed seed for all iterations (common random numbers). Log every iteration (cost, μ, params) to the trace CSV.
B7 — Apps only; long runs are not ctests except §9 tests. The weak-error order is reported, not asserted; the README states the measured number with its SE and the regression range used.
B8 — README must contain: model + scheme with references (BFG 2016, BLP 2017, McCrickerd-Pakkanen 2018 as inspiration, MNT 2004 LM); the deliberate deviation (exact discrete variance c_i instead of t^{2H}); that Greeks are forward-mode AD (dual numbers), not adjoint AD; VR table; convergence plots data; skew-slope table with the flagged asymptotic constant; calibration recovery table (same-seed and different-seed) with the honest statement that it recovers a synthetic surface generated by the same model and scheme; limitations (constant ξ0, r = q = 0, European only, N² cost per path).
