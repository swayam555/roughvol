# quant-cpp — shared plan (architect's decisions, binding for coders)

Two C++20 projects share one build tree and one tiny support library:

| dir | what | namespace |
|---|---|---|
| `common/` | `qc` support lib: Philox RNG, Gaussian/exponential draws, stats (Welford, OLS, KS), deterministic block-parallel loop, timers, test shim | `qc` |
| `orderflow-lab/` | LOB matching engine, Hawkes order flow, execution (AC, BL), Avellaneda-Stoikov MM, impact validation | `ofl` |
| `roughvol/` | rough Bergomi hybrid-scheme MC, VR, BS implied vol, dual-number Greeks, LM calibration | `rv` |

Read order for a coder: this file -> `<project>/DESIGN.md` -> `<project>/TESTPLAN.md` -> `<project>/WORKPLAN.md`.
Shared work packages C0 and C1 (below) must be done before any project package.

## 4. build.sh (repo root, bash, `set -euo pipefail`)

```
./build.sh [preset] [--test] [--clean] [--target T] [-j N] [-- <extra ctest args>]
```
Steps:
1. `ROOT=$(cd "$(dirname "$0")" && pwd)`; `VENV=$ROOT/.toolchain/.venv`; fail with a clear message if `$VENV/bin/python` missing.
2. Create the four wrappers in `$ROOT/.toolchain/bin` if absent (chmod +x).
3. `export PATH=$VENV/bin:$PATH`.
4. `--clean` removes `build/<preset>`.
5. Configure if `build/<preset>/build.ninja` missing: `cmake -S $ROOT -B build/<preset> -G Ninja -DCMAKE_TOOLCHAIN_FILE=$ROOT/cmake/zig-toolchain.cmake -DCMAKE_BUILD_TYPE=... -DQC_SANITIZER=none|undefined|thread`.
6. `cmake --build build/<preset> -j ${N:-${QC_JOBS:-8}} ${TARGET:+--target $TARGET}`.
7. If `--test`: `cd build/<preset> && ctest --output-on-failure -j 4 <preset default label filter> <extra args>`.
   (`-j 4` because stat/slow tests are themselves multi-threaded.)
Exit code = first failing step's exit code.

Acceptance of the build system: `./build.sh release --test` and `./build.sh ubsan --test` both exit 0 on a clean checkout.

## 5. Testing harness

Tests include only `<qc/test.hpp>`, which provides exactly this macro subset (identical spelling to doctest so the file works with either backend):
`TEST_CASE("name")`, `SUBCASE("name")` (doctest only — DO NOT use SUBCASE; keep tests flat), `CHECK(expr)`, `REQUIRE(expr)`, `CHECK_FALSE(expr)`, `CHECK_MESSAGE(expr, msg)`, `REQUIRE_MESSAGE(expr, msg)`, `MESSAGE(msg)`, plus our own function
```cpp
namespace qc::test {
  // true iff |a-b| <= abs_tol + rel_tol*max(|a|,|b|); on failure prints a, b, |a-b|
  bool close(double a, double b, double abs_tol, double rel_tol = 0.0, const char* what = "");
}
```
Use `CHECK(qc::test::close(x, y, 1e-12))`, never doctest's `Approx` (not in the in-house harness).
- If `common/third_party/doctest/doctest.h` exists, `qc/test.hpp` includes it; `common/tests/test_main.cpp` defines `DOCTEST_CONFIG_IMPLEMENT_WITH_MAIN`.
- Otherwise `qc/test.hpp` implements the subset itself (~150 lines): static registry of `{name, fn}`; `CHECK` records failure with file:line and expression text and continues; `REQUIRE` throws `qc::test::RequireFailure` caught by the runner; `main` (in `test_main.cpp`) runs all cases, prints `[PASS]/[FAIL] name`, returns non-zero if any failed; supports `--case=<substring>` filter. The choice is made at configure time: `if(EXISTS .../doctest.h) target_compile_definitions(qc_test_main PUBLIC QC_HAVE_DOCTEST=1)`.
- WP C0 fetches doctest **once**: `curl -fsSL https://raw.githubusercontent.com/doctest/doctest/v2.4.11/doctest/doctest.h -o common/third_party/doctest/doctest.h`. If that fails, do not retry with other sources; write the in-house harness. Either way the tests are identical.

Statistical-test rules (apply in both projects):
1. Every stochastic test uses a fixed seed and is therefore deterministic; tolerances are still derived from standard errors (≥ 4 SE unless stated) so that changing the seed would pass with overwhelming probability. A coder may change a seed **only** to diagnose; the committed seed is the one in TESTPLAN.
2. Never tune a model parameter, tolerance, or seed to make a failing test pass. If a test in TESTPLAN fails after the implementation is believed correct, write the observed numbers into the project's `NOTES.md` under "Open discrepancies" and stop that work package; the architect decides.
3. Each stat test prints (via `MESSAGE`) the estimate, its SE and the target, so logs are diagnosable.

## 6. Coding standards

- C++20, headers in `include/<ns>/`, sources in `src/`, apps in `apps/`, tests in `tests/`, benches in `bench/`.
- Namespaces `qc`, `ofl`, `rv`. No `using namespace` in headers.
- Types: `double` for all real math; `std::int64_t` for quantities and counts; `std::int32_t` for ticks; `std::uint64_t` for ids/seeds. No `float`, no `long double`.
- Errors: invalid configuration/arguments -> throw `std::invalid_argument` with a message naming the parameter and value. Hot paths (book matching, path simulation inner loops) never throw and never allocate after construction/reserve. Expected business outcomes (rejected order, IV below intrinsic) are status enums, not exceptions.
- **Randomness:** only `qc::Philox4x32` + `qc` draw helpers. Forbidden: `rand`, `std::random_device`, `std::mt19937`, every `std::*_distribution` (their output is implementation-defined, so results would change across standard libraries), `time(nullptr)` seeding.
- **Determinism:** results must be bitwise identical for any thread count, on the same binary and machine (cross-machine bitwise identity is NOT claimed: libm `log/exp/cos` may differ). Achieved by: per-block RNG streams (never per-thread), per-block partial results, reduction in block-index order on one thread (see `qc::parallel_blocks`). No floating-point atomics, no `std::reduce` with execution policies.
- No global mutable state; no singletons. `const` and `noexcept` where true. `[[nodiscard]]` on functions returning results/statuses.
- Formatting: 4-space indent, 110-column lines, `snake_case` for functions/variables, `PascalCase` for types, `kConstant` for constants, trailing `_` for private members.
- Every public function has a one-line doc comment stating units (ticks, lots, seconds, years, annualised variance...).
- Apps write results as CSV to `results/` under the project dir (created if absent) and print a short human summary to stdout. CSV columns are listed in each DESIGN.

## 7. common/ (`qc`) API — implement in WP C1

```cpp
// philox.hpp  — Philox4x32-10 (Salmon, Moraes, Dror, Shaw, SC'11 "Parallel random numbers: as easy as 1, 2, 3")
namespace qc {
struct Philox4x32 {
  using Ctr = std::array<std::uint32_t,4>; using Key = std::array<std::uint32_t,2>;
  static Ctr apply(Ctr ctr, Key key) noexcept;   // 10 rounds
};
// Round: (hi0,lo0)=mulhilo32(0xD2511F53, x0); (hi1,lo1)=mulhilo32(0xCD9E8D57, x2);
//        x = { hi1^x1^k0, lo1, hi0^x3^k1, lo0 }.
// apply: x=round(x,k); repeat 9 times { k0+=0x9E3779B9; k1+=0xBB67AE85; x=round(x,k); }

// A stream = (seed, stream_id, purpose); draws are indexed by a 64-bit counter i.
// ctr = { lo32(i), hi32(i), lo32(stream_id), (hi32(stream_id) & 0xFFFF) << 16 | purpose(16 bits) }
// key = { lo32(seed), hi32(seed) }.  stream_id < 2^48, purpose < 2^16 (throw otherwise).
class RngStream {
 public:
  RngStream(std::uint64_t seed, std::uint64_t stream_id, std::uint16_t purpose);
  std::uint32_t next_u32() noexcept;     // buffers the 4 words of each block, in order w0..w3
  double uniform() noexcept;             // in (0,1): m = (u64(a)<<21) | (b>>11); return (m+0.5)*0x1p-53
  double exponential() noexcept;         // -log(uniform())
  double normal() noexcept;              // Box-Muller (basic, not polar), caches the second variate:
                                         // u1=uniform(), u2=uniform(); r=sqrt(-2 log u1);
                                         // returns r*cos(2*pi*u2), next call returns r*sin(2*pi*u2)
  std::int64_t uniform_int(std::int64_t lo, std::int64_t hi) noexcept; // inclusive; lo + floor(u*(hi-lo+1)), clamp to hi
  std::uint64_t draws() const noexcept;  // number of 32-bit words consumed (for tests)
};
}
// stats.hpp
struct RunningStats { void add(double x); std::int64_t n() const; double mean() const; double variance() const /*unbiased*/;
                      double stddev() const; double se() const /*stddev/sqrt(n)*/; void merge(const RunningStats&); }; // Welford/Chan
struct OlsResult { double intercept, slope, se_intercept, se_slope, r2; std::int64_t n; };
OlsResult ols(std::span<const double> x, std::span<const double> y);           // throws if n<3 or var(x)==0
double ks_statistic(std::vector<double> sample, const std::function<double(double)>& cdf); // sup |F_n - F|
double ks_critical_001(std::int64_t n);   // 1.628/sqrt(n)  (asymptotic, alpha=0.01)
double norm_cdf(double x);                // 0.5*erfc(-x/sqrt(2))
double norm_pdf(double x);
// parallel.hpp
unsigned default_threads();               // env QC_THREADS if set (>=1), else std::thread::hardware_concurrency(), min 1
// Runs fn(block) for block in [0,n_blocks) on `threads` std::jthreads pulling indices from an atomic counter.
// fn must only write state owned by its block. Exceptions: first one captured and rethrown after join.
void parallel_blocks(std::int64_t n_blocks, unsigned threads, const std::function<void(std::int64_t)>& fn);
// timer.hpp
struct Stopwatch { void start(); double elapsed_s() const; };  // std::chrono::steady_clock
inline std::uint64_t now_ns();                                // steady_clock ns since epoch
// linalg.hpp  (dense row-major, small n <= 16)
struct Mat { int rows, cols; std::vector<double> a; double& operator()(int,int); double operator()(int,int) const; static Mat identity(int); };
std::vector<double> solve_lu(Mat A, std::vector<double> b);   // partial pivoting; throws std::runtime_error if |pivot| < 1e-300
std::vector<double> solve_cholesky(Mat A, std::vector<double> b); // SPD; throws if non-positive pivot
double spectral_radius_nonneg(const Mat& G);                  // see orderflow-lab DESIGN §4.2
// cli.hpp — apps take only --key=value arguments
class Args { public: Args(int argc, char** argv, std::vector<std::string> allowed_keys); // unknown key -> throws
  std::int64_t get_int(std::string_view, std::int64_t def) const; double get_double(std::string_view, double def) const;
  std::uint64_t get_u64(std::string_view, std::uint64_t def) const; std::string get_str(std::string_view, std::string def) const;
  bool has(std::string_view) const; };
// csv.hpp
class CsvWriter { public: CsvWriter(const std::string& path, std::vector<std::string> header); // creates parent dir
  void row(std::initializer_list<std::variant<double,std::int64_t,std::string>>); }; // doubles printed with "{:.17g}"
```

## 8. How the two projects relate

They are independent products sharing `qc` (RNG, statistics, parallel loop, harness, linalg). Shared conventions: seeds/streams (§6), CSV results, honest-claims policy, TESTPLAN rules. Conceptual link (README of each may mention it, nothing more): orderflow-lab studies market microstructure (how impact arises from order flow), roughvol studies the volatility those dynamics produce at longer horizons (Gatheral-Jaisson-Rosenbaum 2018 relate roughness to order flow via nearly-unstable Hawkes processes — mention only as motivation, do not claim to demonstrate it).

## 10. Top-5 pitfalls (read before coding)

1. **Hidden nondeterminism.** `std::normal_distribution`/`mt19937`-with-distribution, per-thread RNG streams, `std::reduce`, atomics on doubles, or reducing partial sums in thread-completion order all make results depend on library or thread count. Use per-block Philox streams and ordered reduction. A `parallel`-labelled test in each project asserts bitwise equality across thread counts 1/3/16.
2. **Hybrid-scheme indexing and degeneracies (roughvol).** The Riemann weight Γ_k pairs with the increment `dW_{i-k+1}` for k ≥ 2 (k = 1 is the exact Volterra integral `I_i`); the price step from t_{i-1} to t_i must use V_{i-1} (left point) — using V_i introduces look-ahead and breaks E[S_T] = S_0 when ρ ≠ 0. `k^{α+1}-(k-1)^{α+1}` loses all digits for large k unless computed with `expm1/log1p`; the 2x2 Cholesky entry L22 must be computed with the identity 1/(2α+1) − 1/(α+1)² = α²/((2α+1)(α+1)²) (no cancellation; L22 = 0 exactly at H = 1/2). Greeks/calibration still restrict H ≤ 0.49 to stay off the domain boundary.
3. **Hawkes thinning bookkeeping (orderflow-lab).** The upper bound must be the total intensity evaluated *after* decaying to the current time and *after* adding the last jump; decay must precede the accept test; when a non-Hawkes event (cancel, agent action) interrupts, the pending proposal must be discarded and regenerated (valid by memorylessness). Branching ratio ≥ 1 explodes: validate ρ(G) < 1 at construction.
4. **LOB index invalidation and priority semantics.** Unlinking the order being iterated while matching, failing to recompute best price when a level empties, or giving a modified order its old time priority after a size *increase* or price change. Every LOB test calls `check_invariants()` after every operation; the randomized test compares against a naive reference book.
5. **Fooling ourselves statistically.** Seeds/parameters tuned until a plot "looks like" square-root impact, Greeks checked with independent random numbers (FD noise hides errors), calibration "recovery" that only works because the target was generated with the same paths. TESTPLANs therefore pair every same-seed test with a different-seed test, check pathwise Greeks against common-random-number finite differences, and the READMEs may only make the claims whitelisted in each TESTPLAN, with the measured numbers.

Also watch: Black-Scholes inversion for far-OTM prices (always invert the OTM option; accuracy guaranteed only for normalised price ≥ 1e-12), Philox counter overflow (assert draw index < 2^64 — practically never), and zig's first-compile latency (do not mistake it for a hang).
